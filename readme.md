# wechat-mechant

基于 uni-app x / uniCloud 的微信小程序商城项目，包含用户端商城、营销活动、订单流程、个人中心以及后台管理页面。项目适合作为课程设计、毕业设计、商城原型或二次开发基础。

## 项目简介

本项目围绕一个轻量级电商业务搭建，前端使用 `uvue` 页面组织，云端使用 `uniCloud` 云对象和数据库 schema 承载商品、订单、用户、营销活动等数据。当前版本已经完成主要业务页面的美化和示例数据填充，可在 H5、微信小程序等端进行调试。

## 功能模块

- 商城首页：活动入口、推荐商品、商品卡片、秒杀/拼团/领券入口。
- 商品分类：分类导航、商品列表、商品筛选展示。
- 商品详情：商品图、价格、库存、规格信息、加入购物车、立即购买。
- 购物车：商品列表、数量加减、合计金额、结算入口。
- 登录注册：用户登录、注册、基础鉴权流程。
- 订单流程：确认订单、订单列表、订单详情、支付结果、售后相关页面。
- 个人中心：用户资料、地址、会员、优惠券、收藏、客服入口。
- 营销活动：秒杀、拼团、砍价、优惠券中心等示例页面。
- 后台管理：管理端登录、商品管理、订单管理、数据看板、店铺设置、角色管理。
- uniCloud：商城云对象、管理端云对象、数据库 schema 和初始化数据。

## 技术栈

- uni-app x
- Vue 3 / uvue
- uniCloud 阿里云服务空间
- UTS / JavaScript

## 目录结构

```text
.
├── pages/mall/                 # 商城底部 Tab 页面：首页、分类、购物车、我的
├── packages/mall/              # 商城业务分包：商品、订单、营销、用户、售后等
├── packages/admin/             # 后台管理页面
├── uniCloud-aliyun/            # uniCloud 云函数、云对象、数据库 schema
├── utils/                      # 商城鉴权、购物车、分类、mock 数据等工具
├── static/                     # 静态资源和商品示例图
├── docs/                       # 发布文档、CSDN 文档等
├── pages.json                  # 页面路由与分包配置
├── manifest.json               # 应用平台配置
└── project.config.json         # 微信开发者工具项目配置
```

## 本地运行

1. 使用 HBuilderX 打开项目根目录。
2. 在 `manifest.json` 中填写自己的应用标识和微信小程序配置。
3. 关联自己的 uniCloud 阿里云服务空间。
4. 根据 `uniCloud-aliyun/cloudfunctions/common/uni-config-center/uni-id/config.example.json` 创建本地 `config.json`，并填写自己的 `passwordSecret` 和 `tokenSecret`。
5. 运行到 H5 或微信开发者工具进行预览。

## 隐私配置说明

仓库中已避免提交个人开发隐私和生产密钥。以下文件需要在本地自行配置，不建议提交到公开仓库：

- `project.private.config.json`
- `env.js`
- `uniCloud-aliyun/cloudfunctions/common/uni-config-center/uni-id/config.json`
- 各类证书、私钥、支付配置文件，例如 `.p12`、`.p8`、`.pem`、`.key`
- HBuilderX、本地构建产物和调试输出目录

如果要部署到自己的环境，请使用自己的小程序 `appid`、uniCloud 服务空间、支付证书和业务域名。
